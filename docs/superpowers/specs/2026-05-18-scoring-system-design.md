# Tokyo Child Event - 1-100 分制 AI 评分系统设计

**日期**: 2026-05-18
**主题**: 亲子活动 AI 评分系统 (Scoring System) 设计
**状态**: 待审核 (Pending Review)

## 1. 背景与目标
目前平台通过 `llm_classifier.py` 调用的 Gemini Flash 大模型为每个活动输出 1.0-5.0 的推荐分。为提升分数的颗粒度、区分度和主观推荐感，将评分机制升级为 1-100 分制，并采用明确的维度累加逻辑，以规范 LLM 的输出，防止分数过于集中（“端水”现象）。

## 2. 评分逻辑 (Prompt Rubric)
AI 的打分将严格基于四个维度的加和，每个维度满分 25 分，总分 100 分：

### 2.1 教育与启发 (0-25分)
评估活动对儿童心智、认知或体能的成长价值。
- **20-25分**: 极具教育意义（如：科学实验、文化历史展、编程体验、专门的体能训练）。
- **10-19分**: 有一定启发（如：普通的手工制作、绘本阅读、自然观察）。
- **0-9分**: 纯娱乐，或面向成人的讲座，无实质儿童教育意义。

### 2.2 趣味与互动 (0-25分)
评估儿童的参与度和沉浸感。
- **20-25分**: 孩子能全身心投入、高度互动（如：波波池、职业体验、大型游乐设施、户外拓展）。
- **10-19分**: 部分互动（如：观看演出、参观展览、集章活动）。
- **0-9分**: 枯燥，只能被动接收（如：育儿讲座、纯图文展示）。

### 2.3 稀缺与独特 (0-25分)
评估活动的机会难得程度。
- **20-25分**: 极度稀缺或特殊体验（如：一年一度的夏日祭典、名额极少的消防车乘坐体验、限定特展）。
- **10-19分**: 周期性活动（如：每月/每季度一次的常规手工作坊、周末市集）。
- **0-9分**: 随时可去的日常场所（如：普通公园开放日、常设小型图书角）。

### 2.4 父母友好度 (0-25分)
评估带娃参与该活动的省心程度。
- **基础分 10分**。
- **加分项**: 完全免费 (+5)，室内/雨天无忧 (+5)，无需提前预约/随到随玩 (+5)。
- **扣分项**: 价格极其昂贵 (-5至-10)，交通极度不便 (-5)。

## 3. 数据 Schema 变更
- `AGENTS.md` 中定义的 `ai_score` 字段由 `float (1.0-5.0)` 变更为 `int (1-100)`。
- 在大模型输出的 JSON Schema 中新增 `score_reasoning` (string) 字段，强制 LLM 在输出最终分数前，先输出四个维度的打分过程及总和。这利用了 Chain-of-Thought（思维链）原理，确保分数的准确性。

**输出 JSON 示例**:
```json
{
  "age_min": 3,
  "age_max": 8,
  "type": "arts",
  "score_reasoning": "教育:15(手工制作) + 趣味:20(高度动手) + 稀缺:10(每月常规) + 友好:25(免费且室内无须预约)。总计70分。",
  "ai_score": 70,
  "ai_tags": ["免费", "室内", "亲子互动"]
}
```

## 4. 后续影响
- `processor/llm_classifier.py` 的 prompt 需要更新。
- `processor/llm_classifier.py` 的 Pydantic 输出 Schema 需要更新。
- 前端 `docs/assets/app.js` 可基于此分数实现诸如 `🔥 满分推荐 (>90)` 等徽章渲染逻辑。
